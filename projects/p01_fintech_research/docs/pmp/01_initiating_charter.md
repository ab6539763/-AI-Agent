# 01 启动阶段：项目章程、干系人登记册与 FDE 现场调研

## 1. 项目章程 (Project Charter)

| 项目属性 | 内容 |
| --- | --- |
| **项目编号** | P01-FINTECH-RESEARCH |
| **项目名称** | 金融投研与合规风控智能体 (FinTech Investment Research & Compliance Risk Agent) |
| **交付模式** | FDE (Forward Deployed Engineering) 驻场工程化交付 |
| **运行模式** | 100% 离线确定性推理（零外部 API Key 依赖，全链路可审计） |
| **核心目标** | 构建集领域本体（Ontology）、持久化 LLM Wiki、财务比率工具、PII/合规护栏与 HITL 审批流于一体的生产级投研风控系统 |

### 业务痛点与目标
1. **研报知识碎片化**：历史投研纪要、财务指标分散，缺乏跨实体关联与指标冲突校验。
2. **合规与隐私风险**：查询与入库文本中可能夹带个人隐私（PII）或涉及内幕信息（MNPI）的越权请求。
3. **高风险决策缺少人工兜底**：高杠杆、流动性危机等风险信号需要强制进入 HITL（Human-in-the-Loop）合规官审批队列。

## 3. FDE 现场调研结论 (FDE Discovery)

1. **本体先行**：金融机构对“发行人 -> 财务指标 -> 风险信号 -> 合规动作”的因果链路有强 Schema 校验需求，不允许孤立或非法关系边。
2. **Markdown 持久化知识库**：采用 `index.md`、`log.md` 与 `entities/<id>.md`（含 `[[wiki_links]]`）的轻量结构，便于 Git 版本化与人工复核。
3. **离线确定性优先**：所有财务比率计算、关键词检索、正则脱敏与规则拦截均在本地确定性执行，保证结果 100% 可复现。
