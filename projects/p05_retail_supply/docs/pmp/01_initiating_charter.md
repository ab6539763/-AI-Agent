# 01. 项目启动：零售电商与供应链增长智能体项目章程（Project Charter）

## 1. 项目基本信息
- **项目名称**：P05 零售电商与供应链增长智能体（Retail & Supply Chain Growth Agent）
- **项目代号**：`p05_retail_supply`
- **方法论底座**：PMP 全生命周期 × Palantir 风格 Ontology × LLM Wiki × FDE 前线部署工程

## 2. 商业论证（Business Case）
零售与跨境电商在多仓、多供应商及高频大促场景下面临三大核心痛点：
1. **断货与积压并存**：静态补货阈值无法感知季节性波动与供应商交期（Lead Time）违约风险。
2. **促销规则冲突与毛利侵蚀**：多渠道折扣叠加易突破最低毛利率红线（Margin Floor）。
3. **知识孤岛与无审计动作**：运营 SOP、供应商变更与大额采购决策缺乏可追溯的活体知识库与 HITL（Human-in-the-Loop）审批门禁。

## 3. 项目目标与可量化 KPI
- **安全库存预警覆盖率**：100% SKU 实时计算 `days_of_supply` 与供应商交期违约检测。
- **毛利护栏拦截率**：100% 拦截低于 `min_margin_pct` 的动态调价与促销方案。
- **HITL 审批合规性**：大额采购（`qty >= 200` 或 `cost >= $5,000`）与大幅调价（`> 15%`）强制进入买手（Merchandiser）人工审批。
- **离线确定性**：100% 离线可运行、零外部 API 依赖、端到端 Pytest 门禁通过率 100%。
