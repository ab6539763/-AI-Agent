在企业级智能体上线前，我们必须解决三个核心痛点：1）复杂意图误判（用 CoT“让我们一步步思考”提升推理质量）；2）恶意 Prompt 注入与系统提示词套取（用 PromptGuard 前置拦截）；3）大模型输出格式飘忽（用 Pydantic v2 强类型约束 JSON）。今天我们将把这三道防线组装成 CustomerIntentClassifier！

一、三大核心工程防线

防线模块 核心技术 解决的企业痛点

三、核心代码片段速览

1. Pydantic v2 强类型契约

class IntentResult(BaseModel):
    intent: IntentCategory
    confidence: float = Field(ge=0.0, le=1.0, description="置信度，范围 0.0 ~ 1.0")
    reasoning: str = Field(min_length=1, description="CoT 逐步推理过程")
    entities: dict[str, Any] = Field(default_factory=dict, description="提取的关键业务实体")

2. 前置短路拦截（Short-Circuit）

guard_result = self.guard.inspect(user_input)
if not guard_result.is_safe:
    return IntentResult(
        intent="security_blocked",
        confidence=1.0,
        reasoning=f"前置安全守卫拦截：{guard_result.reason}",
        entities={"risk_level": guard_result.risk_level, "matched_rules": guard_result.matched_rules},
    )

点击查看：为什么 MockTransport 在单元测试中至关重要？

通过 httpx.MockTransport，我们可以在完全离线、无 API Key 的 CI 环境中真实走通 httpx.Client.post() 请求序列化、Header 构造、JSON 解析与 Pydantic 校验全链路，同时还能用 spy_handler 精确断言 Prompt 注入被拦截时没有发出任何网络请求。
