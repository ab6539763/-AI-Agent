点击“发送”或按下 Enter 后，浏览器端完成从 DOM 渲染到异步 HTTP POST 请求的完整闭环：

二、三大核心前端技术要点

1. 语义化 HTML5 与核心 DOM ID 规范

DOM ID元素标签核心职责
#chat-messages<section>消息列表滚动容器（aria-live="polite"）
#chat-form<form>统一拦截 submit 提交事件
#user-input<textarea>自适应高度输入框（Enter 发送，Shift+Enter 换行）
#send-btn<button>提交按钮，请求期间自动置灰防重

2. CSS Flexbox 左右对齐气泡

通过 display: flex; flex-direction: column; 配合 align-self，一行 CSS 即可区分用户与助手气泡：

.chat-messages { flex: 1; display: flex; flex-direction: column; gap: 16px; overflow-y: auto; }
.message.user { align-self: flex-end; }
.message.assistant { align-self: flex-start; }

3. 原生 JS fetch() POST JSON 请求

const response = await fetch("/api/v1/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ session_id: sessionId, message: trimmed })
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const data = await response.json();

点击查看课后思考：为什么还要用 Python 写 ui_validator.py？

在多人协作与 CI/CD 流水线中，前端页面可能被误删关键 DOM ID（如 #send-btn）或漏掉 UTF-8 编码导致中文乱码。使用 Python 标准库 html.parser 编写轻量级静态门禁，无需安装 Node/Playwright 即可在 0.1 秒内完成基础结构回归测试。
