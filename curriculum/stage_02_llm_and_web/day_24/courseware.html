2. FastAPI SSE 流式接口与 CORS 中间件

@application.post("/api/v1/chat/stream")
async def chat_stream(payload: ChatStreamRequest) -> StreamingResponse:
    db.save_message(payload.session_id, "user", payload.message)
    full_reply = _generate_assistant_reply(payload.message, history)

    async def event_stream():
        for chunk in _chunk_text(full_reply, chunk_size=4):
            yield f"data: {json.dumps({'type': 'delta', 'content': chunk}, ensure_ascii=False)}\n\n"
        msg_id = db.save_message(payload.session_id, "assistant", full_reply)
        yield f"data: {json.dumps({'type': 'done', 'message_id': msg_id}, ensure_ascii=False)}\n\n"

    return StreamingResponse(event_stream(), media_type="text/event-stream")

3. 前端为什么用 fetch + ReadableStream 而不用 EventSource？

浏览器原生的 EventSource 只支持 GET 请求，无法在请求体（Body）中携带复杂的 JSON 对话历史或鉴权 Token。而使用 fetch(..., {method: "POST"}) 配合 response.body.getReader() + TextDecoder，就能完美消费 POST 接口返回的 SSE 流！
