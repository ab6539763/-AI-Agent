二、Token 是什么？为什么中文比英文更“费”Token？

大模型并不直接认识汉字或英文单词，而是通过 BPE（Byte Pair Encoding） 等子词分词器将文本切分为整数 ID 序列（Token）。在通用词表中：

  • ASCII / 英文单词：常见单词往往整体或按词根切分，平均约 4 个字符 ≈ 1 Token（即 0.25 tokens/char）。
  • CJK 中文字符：由于汉字数量庞大，部分生僻字或词组会被拆分为多个字节级 Token，通用词表下平均约 1.5 tokens/汉字。
def estimate_tokens(text: str) -> int:
    # CJK 字符及全角标点: 1.5 tokens/char
    # ASCII 非空白字符: 0.25 tokens/char
    # 空白字符: 0.1 tokens/char
    raw_tokens = cjk_count * 1.5 + ascii_non_space * 0.25 + whitespace * 0.1 + other * 1.0
    return max(1, math.ceil(raw_tokens))
