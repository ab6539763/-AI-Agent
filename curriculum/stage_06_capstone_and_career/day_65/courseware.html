四、10 分钟企业评委高频硬核问答（点击展开满分要点）

JQ-01 幻觉治理：财报与合规场景如何防止模型胡说八道？

四层防线：1) BM25 + 向量双路召回与 RRF 重排；2) 强制 Citation 原句锚定；3) 上下文缺失或口径冲突时触发低置信度拒答（Abstention）；4) 接入 Faithfulness ≥ 0.85 自动化上线门禁。

JQ-02 高并发成本：早高峰 500 并发下 Token 成本与 P99 延迟怎么控？

四项优化：1) 语义缓存（Semantic Cache）拦截 35%-45% 高频重复问答；2) 大小模型分级路由（Router）；3) Chunk 去重与上下文裁剪；4) 网关租户级 Token 桶限流与降级熔断。

JQ-03 权限隔离：共用向量库如何防越权检索与 Prompt 注入？

纵深防御：1) 文档切片绑定 tenant_id / dept_acl，检索时执行 Pre-filtering 下推过滤（绝不召回后过滤）；2) 输入侧 Prompt 注入拦截；3) PII 入库前脱敏与不可篡改审计日志。

JQ-04 HITL 超时：审批人出差、服务重启或重复点击批准怎么办？

生产可靠性：1) 审批单持久化至 SQLite/PG 支持重启恢复；2) TTL 超时自动流转 expired 并触发企微/邮件升级转派；3) CAS 状态机仅允许 pending 流转，重复提交返回 409 Conflict 并配合幂等键。

JQ-05 微调 vs RAG 选型：为什么不直接用内部文档微调一个大模型？

核心原则：RAG 管动态知识（高频更新、强溯源、文档级 ACL 隔离），微调管行为模式（固化 JSON/Tool-Call 格式、领域话术风格与压缩超长 System Prompt）。
