四、随堂小测（点击展开解析）

问题：为什么 Rerank Top-K 精排裁剪在减少 Prompt Token 成本的同时，还能正向提升 Ragas 的 context_precision？

查看参考解析

context_precision 衡量排序靠前的检索片段中相关证据的加权纯度。通过 Cross-Encoder 将最相关的 Top-2 片段置顶并裁掉尾部无关的制度/行政噪音片段后，既减少了干扰信息（避免 LLM 中间迷失），又直接降低了 Input Token 消耗与预填充延迟。
