1. 需求背景与架构设计（Issue #067）

Tech Lead 张工在组内评审中指出：“面试八股不是死记硬背，而是考察候选人是否真正理解原理 + 瓶颈 + 工程权衡。” 因此，interview_bank.py 将每道题拆解为带权重的 KeyPoint（主描述 + 同义关键词簇），通过 ExamSession 完成均衡组卷、自动判分、薄弱维度识别与靶向学习计划生成。

2. 五大核心技术维度速览

1. Transformer 与推理优化

AttentionKV CacheRoPE

重点掌握：$\sqrt{d_k}$ 方差缩放、KV Cache 从 Compute-Bound 到 Memory-Bound 的演进、PagedAttention、RoPE 外推与 Pre-LN 稳定性。

2. RAG 检索与定量评估

BM25+RRFRerankRAGAS

重点掌握：混合检索与 RRF 免归一化融合、Bi-Encoder 粗排 + Cross-Encoder 精排取舍、RAGAS 四大指标与 Chunking 边界。

3. Agent 架构与 Tool Use

ReActHITLMCP

重点掌握：ReAct vs Plan-and-Execute、Pydantic 参数契约与防死循环熔断、HITL 异步状态机挂起恢复、MCP 协议价值。

4. Python 异步与工程安全

asyncioSSEGuardrails

重点掌握：FastAPI 同步阻塞陷阱与 to_thread、SSE vs WebSocket、Pydantic v2、GIL、Prompt 注入防御与 Mock CI 测试。
