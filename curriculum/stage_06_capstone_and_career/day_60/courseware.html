一、核心混合 RAG 与可溯源引用流水线

全链路分为五大阶段：双路并行召回（BM25 + Vector） → RRF 倒数排序融合 → CrossReranker 精排 → 置信度门控 → 行内引用合成 / 拒答。

flowchart LR Q["用户提问 (Query)"] --> BM25["BM25Index: 稀疏关键词召回"] Q --> VEC["VectorIndex: 稠密语义召回"] BM25 --> RRF["RRF 倒数排序融合 (k=60)"] VEC --> RRF RRF --> RERANK["CrossReranker: 多维语义精排 [0,1]"] RERANK --> GATE{"置信度 >= min_confidence ?"} GATE -->|"低于阈值 / 无命中"| REFUSE["低置信度拒答 (refused=True, citations=[])"] GATE -->|"通过阈值"| CITE["GroundedAnswerGenerator: 证据抽取 + 行内引用 [1][2]"] CITE --> RESP["RAGResponse (Answer + Citations + Trace)"]

二、核心组件与工程职责规范

组件类 / 函数 核心职责 关键工程要点
BM25Index 稀疏关键词精确检索 结合 tokenize_mixed（英文/错误码词元 + 中文 Unigram/Bigram），保障 ERR_502、数字条款零漏召
VectorIndex 稠密向量语义检索 基于 DeterministicEmbedder（Feature Hashing + L2 归一化）与余弦相似度，离线确定性运行
reciprocal_rank_fusion 多路排名融合 使用 $1/(k+\text{rank})$（默认 $k=60$）消除稀疏与稠密分数量纲差异，输出统一 RetrievedChunk
CrossReranker 多信号精排与置信度标定 融合词元覆盖率、术语命中、标题匹配与 RRF 先验，输出归一化 rerank_score ∈ [0, 1]
GroundedAnswerGenerator 行内引用合成与拒答门控 提取最优证据句并绑定 [1]、[2] Citation；低于 min_confidence 时触发防幻觉拒答

三、课后巩固与自测抽查

完整题目与参考答案请查阅 homework_and_answers.md。

自测抽查 1：为什么不能直接用 0.5 * BM25 + 0.5 * Cosine 融合两路检索结果？

BM25 得分无固定上界（常在 2~30 之间），而余弦相似度位于 [-1, 1]，直接线性加权会被 BM25 量纲完全主导。采用 RRF 仅依赖排名位置融合，彻底摆脱量纲干扰。

自测抽查 2：低置信度拒答机制如何防止大模型幻觉？

在生成答案前设置置信度硬门控：当最高 rerank_score < min_confidence 或无命中切片时，直接阻断生成并返回 refused=True, citations=[]，避免模型强行基于无关上下文编造答案。
