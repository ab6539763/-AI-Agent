二、企业团队实战对比：反面方案 vs 标杆方案

❌ 初级直连方案（15/100 · D 级）

  • 仅配置 FastAPI + 单机 FAISS + GPT-4o API
  • 无语义缓存：高频重复问题直击旗舰模型，月度账单高达 ¥67,500（超预算 92%）
  • 无网关限流与熔断：大促流量翻倍即雪崩
  • 无全链路 Trace：无法定位 TTFT 与慢查询根因

✅ 智枢生产方案 v2.0（100/100 · S 级）

  • 向量索引：Milvus HNSW 分片 + BM25 混合检索 + Cross-Encoder 重排
  • 语义缓存：Redis 余弦 ≥ 0.92 命中直出，拦截 35% 请求
  • 成本路由：65% 简单问答路由至 Qwen-7B，月账单降至 ¥18,525
  • 高可用与监控：令牌桶限流 + 供应商熔断降级 + Langfuse/OTel 监控

三、高频 AI 系统设计题库（点击切换）

场景指标：200 QPS | P99 ≤ 1200ms | 月预算 ¥35,000

面试官深挖追问高分回答要点
2000万向量带部门 RBAC 权限过滤召回暴跌怎么办？采用 Partition Key 物理分片 + Metadata Pre-filtering，避免 Post-filtering 剪枝过多。
每日增量更新 1 万篇文档如何近实时生效？Kafka 异步消费 → Semantic Chunking → 幂等写入 Milvus，与在线检索读写分离。

场景指标：1000 QPS | P99 ≤ 800ms | 月预算 ¥85,000

面试官深挖追问高分回答要点
大促峰值翻 3 倍到 3000 QPS 如何防止雪崩？Kong 令牌桶按租户限流 → FAQ 规则/Redis 语义缓存拦截 40%+ 流量 → 异步队列背压。
如何防止 Prompt 注入诱导 Agent 非法退款？输入侧注入检测 + 高危 Tool Call 强制风控校验/HITL 人工二次确认。

场景指标：50 QPS | P99 ≤ 8000ms | 月预算 ¥45,000

面试官深挖追问高分回答要点
多 Agent 链路长达 8 步，死循环或工具失败怎么处理？LangGraph 有界状态机限制 max_iterations <= 8，每步 Checkpoint 持久化支持回滚。
如何彻底杜绝金融财报“数字幻觉”？禁止 LLM 口算，所有同比/估值计算交由确定性 Python 沙箱执行，并强制 Citation 溯源校验。
