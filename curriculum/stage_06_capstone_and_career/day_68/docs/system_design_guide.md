## 一、项目深挖 5 层连环追问模板（以智枢 RAG / Agent 平台为例）

面试官深挖一个项目时，通常会沿着以下 5 层逐级加压：

| 层级 | 面试官典型追问 | 高分回答结构（结论 → 方案 → 量化收益 → Trade-off） |
| :--- | :--- | :--- |
| **L1 架构与选型** | 为什么选 Milvus + BM25 混合检索，而不是只用单路向量检索？ | 单路稠密向量对专有名词、工号、错误码召回弱；我们采用 **BM25 + HNSW 向量双路召回 + RRF 融合 + Cross-Encoder 重排**，Recall@5 从 71% 提升至 92%，代价是增加约 120ms 重排耗时。 |
| **L2 数据与权限** | 100 万文档带部门 RBAC 权限过滤，HNSW 召回暴跌怎么办？ | Post-filtering 在过滤率 > 90% 时会导致 Top-K 不足；我们采用 **Partition Key 按租户/部门物理分片 + Metadata Pre-filtering**，配合 Milvus 动态路由，P99 稳定在 85ms 内。 |
| **L3 性能与成本** | 线上 P99 超过 2 秒、月度 Token 账单暴涨怎么优化？ | 三板斧：**① Redis 语义缓存**（余弦 ≥ 0.92 命中直出，拦截 35% 高频重复提问）；**② 大小模型路由**（65% 简单意图走 Qwen-7B，复杂推理走旗舰模型）；**③ SSE 流式输出**压低 TTFT 至 420ms，月成本下降 68%。 |
| **L4 稳定性与安全** | 上游大模型 API 超时或被 Prompt 注入怎么办？ | **网关令牌桶限流（RPM/TPM） + 供应商熔断器**（失败率 > 20% 自动切备选模型/本地 7B 兜底）；输入侧做 PII 脱敏与注入规则拦截，输出侧做 Citation 溯源强校验。 |
| **L5 可观测与评测** | 你怎么证明你的优化真的有效，而不是“体感变好了”？ | 基于 **OpenTelemetry + Langfuse** 采集全链路 Span（检索耗时、Rerank 耗时、TTFT、Token 消耗），并用 200 条黄金评测集跑 **RAGAS / 幻觉率回归基线**，每次发版自动卡点。 |

## 二、三大高频 AI 系统设计题解速查

### 题目 1：设计一个 100 万文档的企业知识库 RAG 平台（200 QPS，P99 ≤ 1.2s）
- **核心瓶颈**：2000 万 Chunks 检索延迟、增量文档近实时更新、权限隔离（RBAC）、长尾幻觉。
- **架构解法**：
  1. **离线增量流水线**：Kafka 接收文档变更 → 异步解析切片（Semantic Chunking）→ 幂等写入 Milvus（按部门 Partition 分片）。
  2. **在线检索链路**：Redis 语义缓存（Hit 直接 SSE 返回） → BM25 + HNSW 混合召回 Top-50 → 轻量 Cross-Encoder Rerank 取 Top-5（GPU 批处理控时 < 150ms）。
  3. **生成与溯源**：强约束 Prompt 引用 `[doc_id]`，后置规则校验引用真实性。

### 题目 2：设计一个高并发智能客服系统（峰值 1000 QPS，P99 ≤ 800ms）
- **核心瓶颈**：大促流量洪峰雪崩、高频重复问题浪费算力、退款/改地址等高危 Tool Call 越权。
- **架构解法**：
  1. **多层防雪崩**：API 网关按租户/IP 令牌桶限流 → 意图识别前置（FAQ 规则 + Redis 语义缓存拦截 40%+ 流量） → 非核心查询排队背压。
  2. **大小模型分级**：简单物流查询走 7B 模型 + 结构化 Function Calling，复杂客诉情绪安抚走旗舰模型。
  3. **HITL 与熔断**：涉及资金/退款的工具调用强制触发人工确认或风控规则校验；大模型超时 1.5s 立即降级为模板安抚话术。

### 题目 3：设计一个多 Agent 金融研报分析助手（50 QPS，P99 ≤ 8s）
- **核心瓶颈**：多轮 Tool Call 死循环与长耗时、金融数字幻觉、单次请求 30k+ Token 成本极高。
- **架构解法**：
  1. **有界状态机（LangGraph）**：严格限制 `max_iterations <= 8`，每步检查点持久化，支持异常回滚与人工介入。
  2. **确定性计算沙箱**：禁止 LLM 口算财务指标，所有同比/环比/估值计算强制交由 Python 沙箱工具执行。
  3. **中间结果缓存与可观测**：财报解析摘要按季度缓存复用，Langfuse 全程记录每个 Agent 的耗时与 Token 归因。
