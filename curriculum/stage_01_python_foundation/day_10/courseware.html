一、上午：Python 模块、包（Package）与虚拟环境

在企业级项目中，我们绝不会把所有类都堆在一个 app.py 里，也不会把所有第三方库装到系统全局 Python 中：

工程概念 核心文件 / 命令 解决的团队痛点
模块 (Module) exceptions.py / models.py 按职责拆分文件，避免千行大文件难以维护
包 (Package) zhishu_agent/__init__.py 通过 __all__ 统一对外暴露接口，隐藏内部细节
虚拟环境 (venv) python -m venv .venv 项目间依赖完全隔离，防止版本冲突
依赖清单 pip install -r requirements.txt 保证开发、测试、生产环境包版本 100% 一致

二、下午：智枢平台自定义异常体系设计

所有业务异常都应继承自统一的平台基类 ZhiShuError(Exception)，这样上层调用方既能精确捕获特定错误，也能用基类做全局兜底：

classDiagram class Exception class ZhiShuError { +str message +str error_code } class InvalidRoleError { +object role +tuple valid_roles } class ModelConfigError class APIResponseError { +int status_code } Exception <|-- ZhiShuError ZhiShuError <|-- InvalidRoleError ZhiShuError <|-- ModelConfigError ZhiShuError <|-- APIResponseError 
# zhishu_agent/exceptions.py 核心片段
class ZhiShuError(Exception):
    def __init__(self, message: str, error_code: str = "ZHISHU_ERROR") -> None:
        self.message = message
        self.error_code = error_code
        super().__init__(f"[{error_code}] {message}")

class InvalidRoleError(ZhiShuError):
    def __init__(self, role: object, valid_roles: tuple[str, ...]) -> None:
        self.role = role
        self.valid_roles = valid_roles
        super().__init__(f"无效的消息角色: {role!r}，允许的角色为 {valid_roles}", "INVALID_ROLE")

三、下午实战：try / except / else / finally 四段式容错

很多同学只用过 try / except，但在企业级服务中，else 和 finally 同样关键：

  • try：只放可能出错的核心调用（尽量精简，避免掩盖无关异常）。
  • except：按从子类到父类的顺序捕获异常，给出降级方案或告警。
  • else：仅当 try 毫无异常时执行，适合放成功后的统计与后续处理。
  • finally：无论成功与否必定执行，适合关闭连接、释放锁、记录审计日志。
try:
    msg = ChatMessage(role=role, content=prompt)
    reply = model.generate([msg])
except InvalidRoleError as exc:
    print(f"[拦截-角色异常] {exc}")
except APIResponseError as exc:
    print(f"[拦截-接口异常] {exc} (HTTP {exc.status_code})")
except ZhiShuError as exc:
    print(f"[拦截-通用平台异常] {exc}")
else:
    print(f"[成功-else分支] 推理完成，回复长度 {len(reply.content)}")
finally:
    print(f"[收尾-finally分支] 已记录调用审计日志 (model={model.model_name})")

四、随堂自测与课后作业提示

思考题：为什么在编写 except 分支时，必须把 InvalidRoleError 写在 ZhiShuError 之前？

点击查看答案解析

Python 的 except 按从上到下的顺序匹配异常类型。因为 InvalidRoleError 是 ZhiShuError 的子类，如果把 except ZhiShuError: 写在最前面，所有子类异常都会被它提前截胡，后面的细粒度分支将永远无法执行！
